# Pilotry

Tauri、React 與 Ant Design X 組成的通用網頁操作工作台。瀏覽、資料擷取、一般按鈕操作及可重用流程共用同一個 Agent，不依賴特定網站或購票場景。瀏覽器使用 zendriver + CDP；Agent 使用 AI SDK `streamText` 透過 Magpie 串流回覆與呼叫工具。

## 開發啟動

需要 Node.js 22 以上，以及已安裝 zendriver 的 Python 環境。預設使用上一層 `.venv`；其他環境可設定 `PILOTRY_PYTHON`。

```powershell
npm install
npm run dev:stack
```

此指令啟動 Python 引擎（8765）、Agent 串流服務（8766）與 Vite（1420），既有的引擎與 Agent 服務會直接重用。開啟 `http://127.0.0.1:1420`。

Tauri 開發視窗使用 `npm run desktop`，需要 Rust、Cargo 與系統建置工具。它會啟動開發服務；已啟動的服務與 Vite 會直接重用。

```powershell
npm run desktop
```

目前提供開發啟動方式；Python 與 Node 執行環境尚未整合進 Tauri 發行版安裝程式。

服務預設連接埠為 8765 / 8766。可在忽略版本控制的 `.env.local` 設定 `VITE_ENGINE_URL`、`VITE_AGENT_URL`、`ENGINE_PORT`、`AGENT_PORT` 和 `ENGINE_URL`；`dev:stack` 會讀取此檔案。切換連接埠時不必結束其他工作中的服務。

## 瀏覽器模式

- Windows Tauri 桌面版：右側是真實的 WebView2 子網頁，可手動操作與接管；Python 連接這個網頁的 CDP 目標，不另外啟動 Chrome。新工作階段尚未選擇執行環境時會嘗試使用內嵌模式。
- 外置模式：偵測 Chrome、Edge、Brave、Chromium 的安裝位置，也可指定 Chromium 執行檔。未安裝的項目會停用；每種瀏覽器使用獨立的應用程式設定檔，不讀取既有的個人瀏覽器設定檔。
- 本機 CDP：明確選擇要接管的分頁，不自動接管第一個分頁。只允許本機 HTTP 端點；中斷連線不會關閉原宿主。
- 網頁開發預覽仍使用即時截圖，只有 Tauri 桌面版能顯示原生子網頁。macOS / Linux 的系統 WebView 及 Firefox / Safari 尚未提供此 CDP 執行器；可以使用外置 Chromium。

Tauri 子 WebView 使用 `unstable` 功能。外站子網頁沒有本機 IPC 能力；主介面與外站網頁分開管理。內嵌模式目前將一般新視窗連結留在同一個網頁；依賴原始彈出視窗或 `window.opener` 的網站請使用外置模式。切換環境不會搬移 Cookie。

## 使用

- 工作台：輸入網址，透過 Pilotry 對話執行操作；桌面版可使用真實內嵌網頁。
- 版面：對話預設佔分屏約六成，可拖曳分隔線或用方向鍵調整；右上方可切換全寬對話、分屏與全寬瀏覽器。比例與側欄狀態會保留。
- 執行工作區：瀏覽器、執行記錄與頁面資訊共用右側空間。執行記錄分頁內可儲存流程；窄螢幕預設顯示全寬對話。
- 執行記錄：即時顯示操作摘要、工具參數、執行狀態與結果，可展開檢查。
- 流程庫：將成功步驟儲存為流程、預覽與編輯定位，帶入參數後直接重跑。
- 任務管理：儲存任務名稱、網址、操作目標與場景標籤；可把目標送到工作台對話。新增任務不會啟動背景監控，任務狀態目前仍是需求管理資料，不是排程器。
- 資料擷取：取得目前已載入頁面的文字、連結或 HTML 表格，在執行記錄下載 JSON / CSV。文字最多 30000 字元、連結最多 200 筆、表格最多 10 個且每表最多 200 列；不宣稱遍歷整個網站。
- 設定：管理瀏覽器模式、連線狀態、預覽與執行預算。

可在聊天中輸入：

```text
開啟 https://www.cityline.com/，分析頁面並點選一個公開活動連結，讀取新頁面內容。
開啟 https://www.iana.org/domains/reserved，擷取公開連結。跑通後儲存為流程「IANA 公開連結擷取」。
重跑流程「IANA 公開連結擷取」。
```

直接操作真實網站：開啟網址、分析頁面文字、連結與表單，並透過 CDP 點選唯一可辨識的公開連結或一般按鈕。沒有 href 的按鈕使用快照中的元素 ID 和文字定位；沒有 ID 時只允許可見文字唯一相符的按鈕。執行後會驗證頁面或狀態確實改變。登入、驗證碼、敏感資料、確認提交與付款由使用者處理。場景標籤不代表已實作所有表單或交易操作。

## 資料與串流

### 保存與重跑流程

1. 完成一次網頁操作後，在「執行記錄」按「儲存流程」。
2. 選擇成功步驟、確認起始網址。可將點選文字或連結目標設成每次執行前可修改的參數。
3. 到「流程庫」預覽流程，再按「重跑」。每次重跑會建立獨立對話並即時顯示執行進度。

也可以直接對話：「把剛才的成功步驟儲存為流程，名稱叫活動購票入口」或「重跑流程：活動購票入口」。對話會使用流程工具讀取記錄、保存或執行，不會只回覆操作建議。透過對話啟動仍需要模型理解指令；流程本身的正常步驟不再逐步呼叫模型。

正常重跑直接呼叫 Python / CDP，不逐步呼叫模型。定位失效時才以 streamText 的結構化輸出從目前頁面的真實候選項目重新辨識，每次執行最多 3 次。結果無法確認、頁面來源不符，或實際到達網址與預期不符時停止，不會在操作後盲目再點一次。

使用預設參數重跑且整段流程成功時，通過驗證的定位修正會保存，下次可直接執行。若流程已被另行修改，修正不會覆蓋新版。使用不同參數時，當次的定位修正不會改寫預設流程。

流程檔案存放於使用者家目錄的 .pilotry/workflows.json，不受對話記錄截斷影響。可透過 PILOTRY_DATA_DIR 變更資料夾。檔案以原子替換寫入，損毀時回報錯誤並保留原檔。保存的內容只包含操作、定位、參數、網址驗證條件與最近一次執行統計，不包含整頁文字、Cookie 或密碼。

目前流程重用涵蓋開啟、讀取、等待、資料擷取、連結及一般按鈕操作，每個流程最多 256 步。它不新增表單填寫、背景監控或自動付款能力。參數導致後續目標網址改變時，請在流程的進階編輯中同步調整預期網址。

對話與偏好設定存放於目前瀏覽器或 WebView 的 localStorage，最多保留 12 段對話，每段保留最近 60 則訊息與 256 個步驟的操作與頁面中繼資料。每段對話只快取最近一份且小於 128 KiB 的擷取結果；較大的資料請在擷取後下載保留。任務由 Python 引擎保存在記憶體，重啟會清除。目前尚未實作網站訂單擷取。

Agent 使用原生工具呼叫，預設 64 回合、15 分鐘，可在設定調整為 32 / 64 / 128 / 256 回合及 5 / 15 / 30 / 60 分鐘。這是單次工作的資源預算，不是模型額度。工具連續失敗 3 次，或對同一頁面連續分析 6 次仍未變更時會暫停；等待網站載入不計入重複分析。達限後顯示具體原因，可從目前頁面繼續，不自動從起點重跑。

SSE 傳送文字增量、執行狀態與工具事件，不轉送模型隱藏推理。停止回覆會中止模型串流及後續工具呼叫；已交給 Python 的操作可能仍會完成。長期排程與無限循環尚未實作。

Magpie 預設使用 `http://127.0.0.1:3425/v1` 與 `zhipu/glm-5.3-flash`。可使用 `MAGPIE_BASE_URL`、`MAGPIE_MODEL`、`MAGPIE_TOKEN` 調整，憑證僅在服務端讀取。頁面分析資料會傳給所設定的模型服務。

## 驗證

```powershell
npm run build
npm test
node --check agent/server.mjs
node --check scripts/dev-stack.mjs
..\.venv\Scripts\python.exe -m py_compile engine/main.py engine/browser.py engine/magpie.py
..\.venv\Scripts\python.exe -m unittest discover -s engine -p "test_*.py"
cargo check --manifest-path src-tauri/Cargo.toml
```

前端組件位於 `src/components/`，工作區狀態與串流生命週期由 `src/hooks/useWorkspace.ts` 管理。模型服務位於 `agent/server.mjs`；瀏覽器工具的執行限制由 `engine/main.py` 再次檢查。
